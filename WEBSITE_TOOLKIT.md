## Preferred Use

- Keep Unity gameplay inside the WebGL canvas.
- Use Next.js for the website wrapper, landing pages, wallet/onchain panels, and leaderboard shell.
- Use GSAP or Motion for page/UI transitions.
- Use Pixi/Konva for 2D sci-fi overlays, particles, terminal effects, or map-style visuals.
- Use Three/R3F only for website presentation scenes, not Unity gameplay systems.
- Keep the Mochi UI style: black glass, cyan, purple, clean sci-fi terminal panels.
